# Pizza Sales Analysis – SQL & Power BI

## Project Overview
This project analyzes pizza sales data using SQL Server and Power BI.

## Tools Used
- SQL Server
- Power BI
- Excel

## Key KPIs
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## SQL Analysis
- Daily and Monthly Order Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Top 5 and Bottom 5 Pizzas

## Power BI Dashboard
Created an interactive dashboard to analyze pizza sales performance.
